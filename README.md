# MOHSEN - نسخه نهایی شبیه‌ساز دسکتاپی LOGO! Soft Comfort

- **نمای کارگاهی واقعی (PLANT):** نمایش خروجی‌ها به‌صورت موتور چرخان، لامپ راه‌پله، پمپ و مخزن آب، و درب پارکینگ.
- **محاسبه تجهیزات تابلو برق:** پیشنهاد خودکار MCB، کنتاکتور، بیمتال و سطح مقطع سیم بر اساس توان و جریان.
- **کادر پارامتر زیر بلوک‌ها:** نمایش جدول `Ta` و `T` زیر تایمرها و شمارنده‌ها دقیقاً مشابه کتاب.
- **تست قطع برق (Power Failure):** بررسی رفتار حافظه ماندگار (`TONR` و `CTUD`).
- **عیب‌یابی و تمرین کارگاهی** + **خروجی تصویر و گزارش نقشه** + **جدول ارزشی** + **تبدیل خودکار به لدر (LAD)**.
